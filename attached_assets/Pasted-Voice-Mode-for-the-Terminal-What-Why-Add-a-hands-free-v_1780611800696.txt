Voice Mode for the Terminal
What & Why
Add a hands-free "voice mode" to the Agentic Terminal. Today the user types requests into the docked chat box. With voice mode enabled, the chat box disappears and the user simply talks to the agent — speech is transcribed and sent as the query, and the agent talks back out loud in a natural voice while it updates the dashboard. The centerpiece is a glowing sphere that reacts to the conversation and highlights the panel the agent is talking about as it speaks.

Done looks like
A clear control to toggle voice mode on/off in the terminal.
When voice mode is ON, the text chat box is hidden and replaced by a voice interface centered on a glowing sphere/orb.
Hands-free: the terminal is always listening while voice mode is on. The user speaks naturally; their speech is transcribed and dispatched to the agent through the same query flow as typing — no button to hold.
The agent responds out loud with a natural-sounding voice (two-way conversation) and at the same time populates/updates the dashboard panels.
The glowing sphere is alive: it pulses/reacts to the user's voice while listening, and animates to the agent's voice while it speaks, with a calm idle state in between.
As the agent speaks about a specific panel, that panel is visibly highlighted ("the place as it goes") in sync with the narration; the highlight moves as the agent moves on.
While the agent is speaking, the mic does not pick up the agent's own voice (no feedback loop); listening resumes automatically when the agent finishes.
Turning voice mode OFF restores the normal text chat box and stops the mic.
Out of scope
Wake-word activation (e.g. "Hey terminal"). While voice mode is on it just listens; turning the mode off is the off switch.
Multi-language speech recognition / non-English voices.
Voice-based authentication or speaker identification.
Offline / on-device-only speech (cloud services are fine).
Editing the agent's core orchestration logic beyond what's needed to emit spoken narration and panel references.
Steps
Voice mode toggle & interface shell — Add a toggle to enter/exit voice mode. On enter, hide the docked text chat box and show the voice interface with the glowing sphere as the centerpiece; on exit, restore the chat box. Persist nothing fancy — just clean transitions and clear listening/speaking/idle status.
Hands-free speech capture (speech-to-text) — Continuously listen to the mic while voice mode is on, transcribe speech, detect when the user has finished a thought (end-of-utterance), and dispatch the transcript to the existing agent query flow exactly as a typed request would be.
Spoken agent responses (text-to-speech) — Have the agent produce a short spoken narration alongside its dashboard updates, synthesize it to natural-sounding audio using the project's AI integration, and play it back. Suppress/pause listening during playback to avoid the agent hearing itself.
Glowing sphere visualizer — Build the animated orb that reacts to live audio: it responds to the user's mic input while listening and to the agent's voice amplitude while speaking, with a distinct idle state. This is the visual anchor of voice mode.
Panel highlighting synced to narration — Extend the agent response so it references which panel(s) it is discussing, and highlight that panel in the dashboard in time with the spoken narration, moving the highlight as the agent shifts topics. The highlight is a glowing emphasis consistent with the sphere's aesthetic.
Robustness & transitions — Handle mic-permission denial with a clear message, recover gracefully if speech recognition or TTS errors out, prevent feedback between speaker and mic, and make enabling/disabling voice mode reliable mid-conversation.
Notes
Depends on the Agentic Terminal's chat box and agent query/orchestration flow from Task #1; reuse that same query path for voice input rather than creating a parallel agent pipeline.
Reuse the project's AI integration credentials/setup for TTS (and STT if a cloud STT is used) — no user-provided API keys.
Keep the black-and-white minimalist terminal aesthetic; the sphere and highlights should read as glowing accents within that visual language.

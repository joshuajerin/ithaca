To provide the Doomberg platform (the "Service"), **Ithaca** engages the third-party subprocessors listed below. Each is bound by data-protection obligations consistent with our [Privacy Policy](/privacy). We update this list when subprocessors change.

## Current subprocessors

| Subprocessor | Purpose | Data processed | Region |
|---|---|---|---|
| **Clerk** | Authentication and identity | Name, email, authentication metadata | United States |
| **Vercel** | Web/app hosting, analytics, speed insights | Request logs, aggregate usage metrics | Global (edge) |
| **Supabase** | Application database | Account records, sessions, StrategySpecs, traces | Configurable region |
| **DigitalOcean** | Compute and backtest execution | Job/run data, logs | Configurable region |
| **Alpaca** | Market data | Market-data requests | United States |
| **Databento** | Market data | Market-data requests | United States |
| **Sharadar** | Fundamentals / reference data | Reference-data requests | United States |
| **Financial Modeling Prep (FMP)** | Supplementary reference data | Reference-data requests | United States |

For details on the data each market-data provider supplies, see [Third-Party Data Sources](/data-sources).

# Subprocessors

To provide the Ithaca platform (the "Service"), **Ithaca, Inc., a Delaware corporation**, engages the third-party subprocessors listed below. Each is bound by data-protection obligations consistent with our [Privacy Policy](/privacy). We update this list when subprocessors change.

## Current subprocessors

| Subprocessor | Purpose | Data processed | Region |
|---|---|---|---|
| **Clerk** | Authentication and identity | Name, email, authentication metadata | United States |
| **Vercel** | Web/app hosting, analytics, speed insights | Request logs, aggregate usage metrics | Global (edge) |
| **DigitalOcean** | Compute, managed database, object storage, and backtest execution | Account records, sessions, StrategySpecs, traces, job/run data, and logs | United States |
| **Alpaca** | Market data | Market-data requests | United States |
| **Databento** | Market data | Market-data requests | United States |
| **Sharadar** | Fundamentals / reference data | Reference-data requests | United States |
| **Financial Modeling Prep (FMP)** | Supplementary reference data | Reference-data requests | United States |

For details on the data each market-data provider supplies, see [Third-Party Data Sources](/data-sources).

## Changes and notice

We may add or replace subprocessors as the Service evolves. Material changes will be reflected by updating this page and the "Last updated" date. To request advance notice of subprocessor changes, contact [joshuaxjerin@gmail.com](mailto:joshuaxjerin@gmail.com).
